## 🚀 Featured Research & Engineering

### 🤖 Autonomous Robot Navigation System
Developed an autonomous mobile robot navigation system in **Python** with **vision-based environment perception, dynamic obstacle detection and adaptive path re-planning**. The system uses **D* Lite** for efficient re-planning in changing environments and benchmarks **A\*, Dijkstra and D* Lite** using path cost, planning time and search efficiency.

`Python` `Autonomous Navigation` `D* Lite` `A*` `Dijkstra` `Dynamic Obstacles` `Path Planning`

---

### 🧠 CRIS — Corruption Risk Intelligence System
A research-oriented machine learning system for **corruption risk intelligence in financial governance**. The system evaluates **SVM, Random Forest, XGBoost and Stacking Ensembles**, with **Explainable AI** techniques for model interpretation and transparency.

`Python` `Scikit-learn` `XGBoost` `SVM` `Random Forest` `Stacking` `XAI` `Streamlit`

---

### 🎯 Adaptive Technical Interview System
A closed-loop adaptive interview system that combines **Retrieval-Augmented Generation** with **Sentence-BERT semantic scoring**. It retrieves technical context, evaluates candidate responses semantically and adapts question difficulty according to performance.

`RAG` `Sentence-BERT` `FAISS` `NLP` `Semantic Similarity` `Adaptive AI` `Python`

---

### 📈 Explainable Machine Learning for Inflation Forecasting in Türkiye
Research exploring the predictive role of **Turkish Lira depreciation and macroeconomic indicators** in inflation forecasting. The work studies variables such as **TRY/USD exchange rate, CPI, energy prices, imports and exports** using machine learning and explainability methods.

`Machine Learning` `Time Series` `Economic Forecasting` `XGBoost` `Explainable AI` `Python`
